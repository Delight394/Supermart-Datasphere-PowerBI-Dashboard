# Supermart Datasphere Power BI Dashboard

## 📌 Project Overview
Built an interactive Power BI dashboard suite analyzing product performance, customer behavior, sales, and profit across categories, regions, and segments to identify key revenue drivers, profitable customer segments, and areas requiring improvement.

## 🛠️ Tools & Technologies
* **Power BI**: Data modeling, DAX measures, and visual design
* **Power Query**: Data cleaning and ETL transformation
* **Excel / CSV**: Source dataset

## 📊 Key Features & Insights
* **Sales & Profitability Analysis**: Visualizes revenue streams, margins, and profit distribution across product categories.
* **Customer Behavior**: Evaluates segment purchasing patterns and customer performance.
* **Regional & Category Breakdown**: Highlights top-performing regions and category trends to target growth opportunities.
